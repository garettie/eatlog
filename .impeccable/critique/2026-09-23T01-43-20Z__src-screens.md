## Priority issues

1. [P1] Dialogs cross-fade through the sheet. SheetDialog.tsx:121-125 ties card opacity to the same linear progress as the scrim, so for most of the 150ms enter and 90ms exit the calendar and the sheet text are both readable on top of each other (frames at 4.0s and 9.0s). Fix: keep the scrim on progress, front-load the card, e.g. opacity = min(1, progress * 3) with scale 0.92 to 1, so the surface is opaque within the first ~50ms. Command: animate.
2. [P1] Selected state speaks three languages. White sliding pill (SegmentedControl.tsx, MealSelector.tsx: Snack, 1M, kg, Male), tonal fill plus border (MealPortionSelector.tsx:137: All), outlined card (activity level). All and Snack sit in the same review sheet. DESIGN.md chips text is also stale (it calls the white pill a one-off exception). Fix: portion shortcuts adopt the white thumb; update DESIGN.md. MealSelector reimplements SegmentedControl's thumb logic and should compose it. Command: polish.
3. [P1] Color semantics leak. Pin hearts use Error Coral (FoodSearchResultRow.tsx:104, RecentMealsState.tsx:111). "Slower than planned" uses goalRateCaution #f0cc72, next to fat #e5c36c; on screen they are the same gold, which breaks the Nutrient Meaning Rule. Fix: heart uses M3.onSurface filled; caution uses a hue that no nutrient owns, or ink plus the icon. Command: colorize.
4. [P2] Loading seams. ProfileScreen.tsx:167 blanks the whole tab with a spinner on first visit (lazy tab). Diary thumbnails render as empty grey rails for a beat on day change (NutritionCard.tsx:59, plain RN Image, no prefetch). Food search opens to a centered spinner with a floating "Enter manually". Fix: render the Profile layout with last-known values or a skeleton; Image.prefetch adjacent days' photo URIs and fade each thumbnail in on load (JS-only); render pinned rows from SQLite before remote search resolves. Command: optimize.
5. [P2] Navigation motion is unauthored. ProfileNavigator.tsx sets no animation, so Profile to Plan uses the Android system transition, which also double-exposes (frame at 45.5s). Tabs hard-cut. Fix: explicit animation on the Profile stack (slide_from_right or a shared-axis X); tabs may stay instant as an Android convention, but document the choice. Command: animate.
6. [P2] Number and copy slips. signedWeight (AnalyticsScreen.tsx:130) takes its sign from the unrounded value, printing `-0.0 kg/wk`. compactPlanLine (AnalyticsScreen.tsx:753, rendered at 1148) repeats the card above it. Chart ticks are raw max/2 values (3,981, 1,990; 75.6, 72.5, 69.5) instead of round numbers. Dates appear as "Today, Sep 23", "Today · Wednesday, September 23, 2026", "Wednesday, Sep 23", "Mon Sep 21", and "Tue, Sep 22". `Bfast` (MealSelector.tsx:15). Command: clarify, typeset.
