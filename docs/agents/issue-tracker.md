# Issue tracker

Issues and proposed changes live in `garettie/eatlog` on GitHub. Use the configured remote to confirm the repository before changing an issue or pull request.

- Read the issue body, comments, and labels before working on it.
- For triage labels, use [triage-labels.md](triage-labels.md).
- GitHub issues and pull requests share a number space. Confirm which kind of item a number identifies.
- Use the authenticated `gh` CLI when available. For multiline bodies, write the text to a file and use `--body-file`.
- Creating or commenting on an issue requires authorization to publish that content. A local review does not imply permission to post it.
- Direct Git pushes to an SSH remote do not require `gh` authentication.
